Description  : High-performance desktop application developed in Dart/Flutter
               for automated querying, inspecting, and exporting product test
               records, process/barcode history, and BOM component
               traceability from the Foxconn CloudMES system.

Key Features:
- Consolidated 3-Tab Settings Bento Dialog: Re-architected settings into 3
  balanced Bento Grid tabs (CloudMES & CDP, Display & Appearance, About & Updates)
  with responsive Expanded navigation, independent PageStorageKey scroll positions,
  dynamic Graphic Tier live-preview tuning, and full Vietnamese/English/Chinese localization.
- Standard Windows Installer & Uninstaller Suite: Complete non-admin deployment
  package with install.bat, uninstall.bat, and uninstall.ps1, supporting custom
  target directory, automatic desktop and start menu shortcuts, and clean uninstall
  registry integration.
- LAN OTA Auto-Update & Installer System: Enterprise-grade over-the-air update
  pipeline supporting UNC/SMB network shares (with optional Windows net use
  credentials), SemVer engine, Zip Slip protection, automatic apply_update.bat
  generation with user config/logs protection and auto-rollback.
- Bento Frosted Glass Update Prompt: Elegant modal with version comparison,
  package size, release notes viewer, and live download/extract progress indicator.
- Dedicated Settings Tab 5 (OTA Update): Full control over update server path,
  network credentials, manual update check, and check interval schedule.
- Barcode History & WIP Components Data Enrichment: Added Line, Internal SN,
  Equipment No, Product Version, Plan No, Remark, and Location (WIP), with
  multilingual translations and expanded CSV exports.
- Sidebar Dense 2-Line SN Card: Rebuilt SN queue cards with status icon,
  primary SN, tab-specific record count badge, action buttons on line 1, and
  clean alternate SN chip + Next Station badge on line 2.
- Translucent Glass Highlight (JA_IQ5_Flash pattern): Refined card background
  using Color.alphaBlend (8% light / 16% dark tint over frosted base), softer
  luminous borders, and ambient glow shadow.
- Asymmetric Bounce Marquee: Smooth pause-scroll-bounce marquee text for long
  primary SNs, alternate SNs, Next Station badges, and Component Trace CSNs.
- Streamlined Records Header: Stripped redundant text badges to prevent clipping,
  creating a dedicated search, route badge, and quick-filter toolbar.
- Command Palette (Ctrl+K / Cmd+K): spotlight-style search over every tab,
  action, and setting, with keyword filtering and arrow-key navigation.
- Bento Glassmorphism Architecture: Modern layout inspired by Apple Liquid
  Glass, Bento Grid, Dynamic Island, and GPU-composited drifting Mesh Orbs.
- Four Data Views: Test Record, Barcode History (process routing), Component
  List (WIP BOM / material traceability), and Component Trace (reverse
  lookup from component CSN to host product SN).
- Live-Preview 4-Slider Glassmorphism Controls: Real-time interactive
  sliders for Card Blur (0-40px), Card Opacity (5-100%), Dialog Blur (0-40px),
  and Dialog Opacity (10-100%) in Advanced Settings, with instant UI updates,
  Default reset, and Cancel rollback.
- 1-Click Direct Theme Switcher: Instant seamless toggle between Light and
  Dark mode.
- Precise Automatic Build Timestamping: Automatically extracts accurate build
  date/time from compiled data/app.so and executable, displayed in Header & About.
- Component Trace with Persisted History: Independent sidebar search history
  persisted across app restarts, with matching Search/Sort and CSV I/O.
- Automatic SN Master Resolution: Internal SNs auto-resolve to canonical product
  SNs, displayed as "typed SN -> resolved SN" with next-process chips and
  asymmetric marquee scrolling.
- Route Badge: Displays the SN Master route name (falling back to route code)
  on the records header whenever route data is available.
- Smart Test Record Fallback: When Test Record has no rows on first app load,
  a newly searched SN, or an explicit Test Record refresh, the app opens Barcode
  History automatically while preserving manual Test Record tab selection.
- SN Data Status Colors: A missing Test Record with Barcode History or Component
  List data is shown in amber; red is reserved for an SN with no data in all views.
- Windows Locale First-Run Language: On first launch, language defaults from
  Windows locale (Vietnamese, Chinese, or English) unless the user has saved a
  language preference.
- Command Palette Glass Polish: The command palette follows Dialog blur/opacity
  settings, with one backdrop blur and a theme-aware Material card.
  Search focus remains delayed after the opening transition.
- iOS-style Smooth UI Transitions: Animated tab/SN switching, cascading list
  entrances, scale+fade dialogs, and crossfaded themes.
- Excel-style Search Filter & Sort-by on every record list, with frosted glass
  Sort dropdowns using real BackdropFilter blur.
- Selectable & copyable record text throughout the UI, including sidebar queue.
- Per-SN and Refresh-All buttons for instant on-demand data refresh; Refresh All clears cached SN Master resolution data before fetching.
- Dynamic Island Status Capsule & Hover-expand Quick Action Toolbar.
- Chrome DevTools Protocol (CDP) Network Interception for 100% accurate Token,
  UUID, Operation-ID & Cookie extraction.
- Persistent Chrome and Edge browser profiles preserve login sessions and passwords.
- Smart CSV Batch Import (auto-skips header rows) & Full CSV Export.
- Automatic startup token verification and background check every 3 minutes.
- HTTP Header Sanitization (fixes \r\n and quote anomalies).
- Daily Log Management & 7-day automatic cleanup.
- Bounded parallel SN query queue with stale-result protection, shared SN Master
  resolution, and refresh-safe loading state updates.
- Restored compact four-tab desktop composition with native Windows caption
  controls kept as the single minimize/maximize/close control set.
- Multi-language UI (English, Vietnamese, Chinese).
