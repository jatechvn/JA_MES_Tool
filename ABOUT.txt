Description  : High-performance desktop application developed in Dart/Flutter
               for automated querying, inspecting, and exporting product test
               records, process/barcode history, and BOM component
               traceability from the Foxconn CloudMES system.

Key Features:
- Three data views per SN: Test Record, Barcode History (process routing),
  and Component List (WIP BOM / material traceability).
- Automatic SN Master Resolution: typed internal SNs are auto-resolved to
  the canonical product SN (snMaster/getSnMasterProcess) before fetching,
  shown as "typed SN -> resolved SN" in the header.
- iOS-style Smooth UI Transitions: fade+slide tab/SN switching, cascading
  list-item entrance animation with bouncing scroll, scale+fade dialog
  presentation, animated sidebar selection & record-count badge, and
  crossfaded light/dark theme switching.
- Excel-style Search Filter & Sort-by (click to toggle ascending/descending)
  on every record list, with a per-field icon and an accent-colored selected
  pill matching the rest of the app's design language.
- Selectable & copyable record data via native text selection, including the
  SN queue sidebar.
- Per-SN and Refresh-All buttons to re-fetch data on demand without
  restarting the app.
- Dynamic-Island-style hover-expand toolbar: compact icons by default,
  full labels on hover or when the window is maximized.
- Automated SN Queueing & Parallel Test Record Fetching.
- Automatic SN Queue Refetch upon Saving Settings.
- Smart CSV Batch Import (auto-skips header rows like "SN") & Full CSV Export.
- Chrome DevTools Protocol (CDP) Network Interception for 100% accurate Token,
  UUID, Operation-ID & Cookie extraction.
- Smart 2-Step Auto Sync Wizard (Open Browser -> Sync Credentials).
- Collapsible Advanced Settings panel for clean & easy navigation.
- Glassmorphism Advanced Settings: live-preview blur/opacity sliders for the
  main background and dialogs, with a built-in legibility floor preventing
  text overlap and see-through glitches.
- Frosted-glass Sort dropdown with real BackdropFilter blur.
- Automatic background Token validation every 3 minutes with status badge.
- HTTP Header Sanitization (fixes \r\n Carriage Return & quote errors).
- Daily Log Management & 7-day automatic cleanup.
- Multi-language UI (English, Vietnamese, Chinese) with Dark/Light Mode.
